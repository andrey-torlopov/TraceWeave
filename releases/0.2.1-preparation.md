# 0.2.1 — graph menus, editor width and attachment refresh

Graph action menus use a portal outside the transformed canvas, keeping their screen size across zoom levels. Menus retain keyboard navigation, focus return, outside dismissal and viewport bounds.

The full document editor starts at 1000 px on desktop and can be resized with the edge handle or arrow keys. The preferred width is saved separately for each user/project in this browser. Narrow screens clamp the visible width without discarding that preference. Existing view preferences migrate to WorkspaceUI version 6.

After the server confirms attachment detachment, the completed upload status is removed immediately from every view. Lost-response retry keeps the exact operation until confirmation. Detachment preserves the original in the project library.

Maintenance HTML uses a native Caddy heredoc, preserving newlines without visible escape text or displaced content.

API 1.4.0 and database schema 11 remain unchanged. No migrations or dependency changes. Same-schema updates retain existing gateway/database/tools; full installations receive the coordinated images. Image-only rollback to 0.2.0 is supported when migration histories match. Publication does not update existing installations.

Local verification passed: frontend build/typecheck and 101 unit tests; Chromium E3 35 and E4 12; delivery 161 unit tests, contract validation and 8 release self-tests. One existing lost-response browser test had a synchronization race; it now waits for retry to be enabled before reading the committed server record, retaining all replay expectations. Native publication, anonymous installation and published update acceptance are required before stable promotion. Real Safari and Firefox are not covered by these checks.
