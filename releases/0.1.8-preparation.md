# 0.1.8 — publication candidate

Card attachments now appear as buttons with their kind and original filename. Select a picture, audio or video to see one preview; arbitrary files download for opening locally. Switching stops the previous player. Files can be added together or consecutively; detaching removes only the selected binding and keeps the original and other attachments.

OpenAPI 1.3.0 and migration history 1–10 are unchanged. Updates from 0.1.7 replace the applications while retaining PostgreSQL, gateway and the exact installed backup tools. Same-schema image rollback to 0.1.7 is supported and must preserve documents and originals. Earlier schema versions migrate to 10 with a coordinated tools upgrade; their image-only rollback remains refused, requiring verified backup restore into new volumes.

The update matrix covers 24 previously published baselines on native amd64/arm64, producing 15 exact tools/infrastructure variants. Source checks include build/typecheck, 95 frontend unit tests, 11 real-server Chromium scenarios, and delivery checks. Publication also runs the Chromium media suite against the actual built candidate on amd64 before exporting images.

Native publication, anonymous registry and 48 application updates are pending. Stable remains 0.1.7 until all gates pass. Real Safari, Firefox and full P0 acceptance are separate. Existing installations are not automatically updated by publishing this release.
