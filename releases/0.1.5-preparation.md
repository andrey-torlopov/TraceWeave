# 0.1.5 — candidate not promoted

Version 0.1.5 has published immutable Git tags and Docker Hub images. It was **not promoted to stable** and no GitHub Release was created. Stable remained 0.1.4 when this candidate was rejected. The corrected release is [0.1.6](0.1.6-preparation.md); published 0.1.5 tags and images must not be rewritten.

## Recorded checks

| Check | Result | Evidence |
| --- | --- | --- |
| Native image build, validation and full Docker publication | PASS on amd64 and arm64 | [Publication 38145473227](https://github.com/andrey-torlopov/TraceWeaveBackend/actions/runs/38145473227) |
| Anonymous clean-host registry acceptance | PASS on amd64 and arm64 | [Registry verification 38147227982](https://github.com/andrey-torlopov/TraceWeave/actions/runs/38147227982) |
| Updates from nine published baselines on two architectures | FAILED in all 18 cases at `safety_backup_restores_new_schema` | [Application update 38147229788](https://github.com/andrey-torlopov/TraceWeave/actions/runs/38147229788) |

All update cases reached the safety-backup recovery check after the preceding 11 checks. Reading an export job with GET after restoring the safety backup failed: restore had stored an interrupted-job error with `code` and `message`, but without the required `fields` array. The backend decoder could not read that error record. This was a product defect; acceptance expectations were retained.

## Included scope

The candidate contained arbitrary attachments and PDF downloads, independent repeated attachments, authenticated native media/download handling, and a readable report ZIP alongside raw export. It used OpenAPI 1.3.0 and additive migrations 8–9, coordinated backup-tool updates and backup/restore support for `files/` originals.

The 0.1.6 correction writes complete interrupted-job errors and reads historical errors that omitted the field list. It adds no database migration or API contract revision. The corrected release has its own publication and acceptance record. The successful build and registry checks above do not qualify 0.1.5 for promotion.
