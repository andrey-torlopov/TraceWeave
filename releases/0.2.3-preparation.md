# TraceWeave 0.2.3 — candidate preparation

Status: source candidate; not published. Stable remains 0.2.2. No image, version manifest, source tag or publication selector is changed by this work.

Dossier reads the existing graph/documents in a catalogue/list/gallery, with safe lazy covers, type filtering, current server-search fields, explicit pagination, relation direction and parallel edges, deep links/history and show-in-graph navigation. Read, edit and quick preview share one DocumentStore and existing revision/idempotency/conflict handling. The quick preview is read-only; Edit/Delete appear above the content and editing uses the full card. Resources precede the note; empty resources/properties are omitted. Reading minimum is 1200 CSS px, editing minimum 1000 px, both viewport-clamped with the existing project width preference.

API 1.4.0, schema 11, runtime backend, migrations, dependencies and lock files remain unchanged. Only local UI preferences advance to WorkspaceUI v7; old viewport/width settings migrate. New workflow-state/alt/event-date/caption-author fields, manual reading order and event-date sorting are not fabricated from the design prototype. Existing attachment captions/provenance/evidence are reused.

Native Linux publication, anonymous image installation and the complete application-update matrix must be run for the exact frozen sources before any future stable promotion. This source-only candidate is not an instruction to update an installation.
