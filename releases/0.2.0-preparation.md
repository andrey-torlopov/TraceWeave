# 0.2.0 — portable projects and document symbols

A full project ZIP can be imported into another account or installation as a new investigation. It carries active/deleted records, catalogs, attributes, groups/layouts, relations, the complete material library and immutable originals, report definitions/snapshots and the exporting tab's presentation. Validation completes before atomic creation; UUIDs and typed internal links are remapped with stable retry identity. Unknown archive versions/features are rejected without dropping fields. Writer format 2.0 pins schema and producer metadata independently of the database version; both historical 1.0 profiles remain readable.

The document editor now uses an accessible icon grid for semantic types. One qualified Emoji 17.0 sequence may override the selected document's icon without changing its type or other cards. Reset restores the built-in icon. Emoji survives saving, duplicate, graph rendering and portable transfer.

OpenAPI advances to 1.4.0. Additive migration 11 introduces nullable document emoji, investigation presentation/provenance and durable import validation metadata. Migrations 1–10 remain byte-identical. Existing pending requests retain their exact bytes and reviewed client hashes. Local draft records migrate to version 2 without rewriting pending requests. The saved status appears after pending receipt cleanup.

Schema upgrades require coordinated tools updates and verified backup before migration. Image-only rollback to schema 10 is refused; restore a verified previous backup into new volumes. Publication does not automatically update existing installations.
