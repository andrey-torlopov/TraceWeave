# 0.1.7 — release notes

Adds the ordinary **Улика** (Evidence) card type with the magnifying-glass icon 🔍 (`search`). The icon already belongs to the local application set; no new image or library is downloaded.

New investigations include the type immediately. Additive migration 10 adds it to existing active and archived investigations without changing document contents, user assessments, revisions or command history. Existing types with code `evidence` or the same Russian name (case/space variants included), including hidden types, are preserved without duplication. The migration does not reinterpret evidence as confirmed information.

The API remains OpenAPI 1.3.0 with identical bytes. Database history advances from schema 9 to schema 10; migrations 1–9 are unchanged. Update the delivery checkout and run bootstrap with the same runtime as described in the [update guide](../docs/en/releases.md). Bootstrap backs up and verifies the installation before migrating. Retained gateway/PostgreSQL images stay selected; backup tools update through an explicit reviewed transition.

Updates from 0.1.6 with retained infrastructure need a manifest matching both the installed application/tools version and the gateway version. The controller checks the more specific `0.1.7-update-from-0.1.6-infra-VERSION.json` before the infrastructure-only variant; all image and source validations remain required.

Image-only rollback from schema 10 is refused. Restore a verified backup into new volumes using the current CLI or use a compatible correcting release. Existing installations are not updated by publication itself.

Local checks: real PostgreSQL migration and persistence tests; Chromium selection/save/reload/icon scenario; native HTTP and both raw/readable exports; backend/frontend build and unit/contract checks. Publication and CI for the exact 0.1.7 revision passed on native amd64/arm64. Anonymous installation passed on both architectures, as did all 28 guided updates from 14 published baselines, including retained-infrastructure 0.1.6 variants. Checks cover the evidence type in existing and new investigations, persistence, both exports, original file bytes, backup/restore and incompatible rollback refusal.
