# 0.1.9 — release notes

Cards switch to centered round icons after shrinking by the configured factor: 1.1–10, default 3. Icon diameter is independently configurable from 1–4 card heights, default 2. Both inputs accept decimal points or commas. Icons continue shrinking with graph zoom; edges, handles and saved node positions remain consistent. UI preferences migrate without resetting valid existing thresholds, panels or viewport. View changes do not mutate documents or server revision.

OpenAPI 1.3.0 and migration history 1–10 are unchanged. Updates from 0.1.7/0.1.8 retain PostgreSQL, gateway and exact installed backup tools. Same-schema image rollback is supported with the same runtime. Earlier schemas migrate to 10 with a coordinated tools upgrade; image-only rollback across schemas is refused in favor of verified backup restore into new volumes.

The update matrix covers all 40 previously published baselines on native amd64/arm64, with 21 exact tools/infrastructure variants. Variant discovery uses both installed tools and gateway versions because repeated same-schema updates can share an application version while retaining different tools. All existing image/source/history validation remains enforced.

Verification is in progress; stable remains 0.1.8 until every gate passes. Real Safari, Firefox and full P0 acceptance are separate. Publication does not automatically update existing installations.
