# Как работает TraceWeave

*[English](../en/architecture.md)*

TraceWeave работает на компьютере или сервере, где вы запускаете Docker. Браузер получает интерфейс и обращается к единой входной точке. Сервис приложения проверяет вход и права, сохраняет тексты/связи в PostgreSQL, а оригиналы вложений — в отдельное файловое хранилище.

| Часть | Что делает |
| --- | --- |
| Браузер | Показывает граф и документы; держит дополнительные черновики и настройки |
| Gateway | Принимает HTTP локально или HTTPS на сервере; направляет запросы |
| Интерфейс | Отдаёт браузеру собранные файлы приложения |
| Сервис приложения | Проверяет доступ, записывает и читает исследования/файлы |
| PostgreSQL | Хранит документы, связи, положения, аккаунты и служебные записи |
| Административные инструменты | Запуск, обновление и согласованный backup/restore по команде оператора |

Исходники компонентов приватны; запуск готового выпуска не требует доступа к ним. Публичная поставка содержит команды управления и закреплённые версии образов. Контейнеры запускаются у вас; Docker Hub служит источником скачивания программ.

Полные схемы, таблица хранения, внешние соединения и границы доверия: **[Данные и безопасность](data-and-security.md)**.
