# Установка

*[English](../en/installation.md)*

Основной путь — [быстрый старт](quick-start.md) с готовыми публичными образами. На хосте не нужны Swift, Node.js или отдельный PostgreSQL. Установите Docker Engine либо Docker Desktop с Linux-контейнерами, Compose и запустите Docker:

```sh
docker info --format '{{.ServerVersion}}'
docker compose version
```

Поставка проверялась с Engine 29.8.2 / Compose 5.5.1; серверный Compose использует `!override`, который должен поддерживаться вашей версией. Выпуск 0.1.1 содержит образы для Linux amd64/arm64; на macOS они работают через Linux-среду Docker.

## Runtime и CLI

По умолчанию настройки, секреты, состояние и резервные копии находятся в `runtime/` внутри каталога установки. Другой **абсолютный** путь задаётся до bootstrap и используется во всех последующих терминальных сессиях:

```sh
export TW_RUNTIME_DIR="$HOME/traceweave-runtime"
./bootstrap.sh
```

Это не перенос файлов PostgreSQL/вложений: они остаются в отдельных Docker volumes. Bootstrap не предлагает выбрать произвольную папку для базы или оригиналов. [Таблица хранения](data-and-security.md#где-лежат-данные).

CLI использует host Python при наличии, иначе — закреплённый tools image. В Docker-only режиме нужен локальный Unix Docker socket; удалённый TCP Docker context этим режимом не поддерживается. Управляющий контейнер имеет полномочия оператора Docker: доверяйте ему как административной программе.

## Локально и на сервере

Локальная установка доступна только через `127.0.0.1`; SMTP/домен не требуются. Bootstrap просит email, имя и скрытый пароль, подтверждение пароля; допустимо от 3 Unicode scalar values до 1024 байт UTF-8. Для реального использования выберите длинный уникальный пароль.

Для [VPS](server-deployment.md) нужны ваш домен, DNS, HTTPS и настроенный SMTP для подтверждения первого email. `smtp://` требует STARTTLS, `smtps://` — TLS. Пароли вводятся отдельно скрыто. Регистрация выключена по умолчанию; включайте её осознанно. База и сервис API не публикуют портов на хост.

Применяйте bootstrap/traceweave.sh; штатные команды проверяют совместимость и состояние. Для backup/restore/update см. [эксплуатацию](operations.md) и [релизы](releases.md). [Границы защиты](data-and-security.md) нужно прочитать до загрузки чувствительных материалов.
