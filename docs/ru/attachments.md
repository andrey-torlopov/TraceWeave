# Файлы и вложения

*[English](../en/attachments.md)*

Подготовлено для версии 0.1.5. Доступные опубликованные поставки перечислены в [руководстве по выпускам](releases.md).

В разделе «Материалы» карточки нажмите «Добавить файлы». Можно выбрать несколько файлов, в том числе PDF, документы, таблицы, архивы и файлы без расширения. Фильтр «Все файлы» показывает весь набор; фильтры изображений, аудио и видео помогают выбрать нужный материал.

Лимит одного файла — до 512 МиБ. Администратор может установить меньший лимит; фактическое значение показано рядом с выбором файлов. Дождитесь состояния «Прикреплено»: выбранный файл сначала загружается, затем связывается с карточкой.

- Изображения, аудио и видео сохраняют существующий просмотр. Поддержка воспроизведения зависит от браузера и кодека; оригинал можно скачать.
- Остальные файлы показываются со скрепкой и исходным именем. Нажмите имя, чтобы скачать оригинал.
- PDF в этой версии скачивается для просмотра в отдельном приложении; встроенного предпросмотра нет.

Один файл можно прикрепить к разным карточкам. Повторный выбор того же файла создаёт отдельное вложение. «Отсоединить» убирает привязку к карточке и сохраняет оригинал в исследовании.

При прерывании загрузки используйте «Повторить загрузку». Если ответ на сохранение не подтверждён, интерфейс предлагает проверить сохранение; это предотвращает повторное прикрепление при сетевом сбое.
