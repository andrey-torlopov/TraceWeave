# Соединение браузера и сервера

*[English](../en/api.md)*

Браузер обращается к тому же адресу, с которого открыт TraceWeave. Указывать отдельный адрес API или открывать порт PostgreSQL не требуется. Доступ к исследованиям и оригиналам требует входа. В режиме VPS используйте HTTPS.

При конфликте сохранения интерфейс сохраняет ввод и предлагает сверить версии. Во время обслуживания дождитесь завершения операции; при нехватке места обратитесь к оператору. Не очищайте browser storage, пока нужен несохранённый черновик.

Полный сторонний программный API и стабильный SDK этим руководством не обещаются. [Эксплуатация](operations.md) · [Данные и безопасность](data-and-security.md).
