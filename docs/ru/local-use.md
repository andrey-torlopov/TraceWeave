# TraceWeave на своём компьютере

*[English](../en/local-use.md)*

Следуйте [быстрому старту](quick-start.md). Готовый выпуск скачивается из публичного реестра и работает на вашем компьютере. Откройте http://127.0.0.1:8080; эта loopback-точка не доступна другим компьютерам сети.

```sh
./traceweave.sh status
./traceweave.sh stop
./bootstrap.sh
```

Остановка и перезапуск сохраняют базу, файлы и аккаунты. Подтверждённые данные приходят с сервера; браузер хранит дополнительные локальные черновики и настройки. Очистка данных сайта может удалить несохранённые черновики.

После скачивания образов работа с уже загруженными материалами в локальном режиме не требует интернета. Новая установка и скачивание обновлений требуют сети. Перенос только папки установки не переносит Docker volumes. Создавайте [резервные копии](operations.md) и храните их отдельно.
