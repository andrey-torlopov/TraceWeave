# Быстрый старт

*[English](../en/quick-start.md)*

Для запуска нужны Docker с Linux-контейнерами, Docker Compose, Git и интерактивный терминал. Исходники компонентов и учётная запись GitHub/Docker Hub не нужны. Образы выпуска 0.1.0 публичны для amd64 и arm64.

Из каталога, где будет храниться новая установка:

```sh
git clone https://github.com/andrey-torlopov/TraceWeave.git
cd TraceWeave
./bootstrap.sh
./traceweave.sh status
```

Bootstrap скачает закреплённые образы, подготовит хранилище и запросит email, имя и пароль с скрытым вводом. Откройте **http://127.0.0.1:8080** и войдите. Создайте исследование, два документа и связь; после подтверждённого сохранения перезагрузите страницу.

Папка `releases/` содержит проверенный выбор 0.1.0. Для точной установки ранее опубликованного выпуска используйте [инструкцию релизов](releases.md). Клонирование текущей документации не меняет версию установленных контейнеров.

```sh
./traceweave.sh stop
./bootstrap.sh
```

Остановка сохраняет данные и выбранный выпуск. Повторный bootstrap запускает существующую установку. Сохраните её runtime и Docker volumes. При занятом порте новая установка допускает `./bootstrap.sh --port 18080`; её адрес будет http://127.0.0.1:18080.
