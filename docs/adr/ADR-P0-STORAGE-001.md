# ADR-P0-STORAGE-001 — PostgreSQL вместо SQLite

**Статус:** принято владельцем 2026-10-08 в ТЗ 1.1, §2.2. Эта карточка индексирует уже принятое решение, не создаёт вторую нормативную редакцию.

Полная запись решения, варианты, последствия, влияние на данные/API и проверки находятся в [единственном нормативном ТЗ, §2.2](../TECHNICAL_SPECIFICATION.md#adr-p0-storage-001).

## Применение в workspace

- PostgreSQL — единственная основная БД P0; Fluent + FluentPostgresDriver.
- Файловые оригиналы остаются вне webroot; Docker не становится обязательным.
- В AGENTS.md исправлены прежний выбор SQLite и критерий сохранения E2.
- Существующих исходников приложения, миграций и runtime-БД в предоставленном workspace не обнаружено. Миграция пользовательских данных не выполнялась.
- Блокировки, FTS/GIN, конкурентная идемпотентность и backup/restore должны быть проверены на настоящем PostgreSQL. Статус этих проверок сейчас `not_run`.

Эта синхронизация закрывает подготовительную часть OQ-07; не подтверждает совместимость стека или завершение E0.
