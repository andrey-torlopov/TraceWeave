# Browser and Server Connection

*[Русский](../ru/api.md)*

The browser connects to the same address that serves TraceWeave. No separate API address or PostgreSQL host port is needed. Investigations and original files require sign-in. Use HTTPS for a VPS.

On a save conflict, the interface retains input and offers version reconciliation. Wait for maintenance to finish; contact the operator if storage is full. Keep browser storage while an unsaved draft is needed.

This guide does not promise a complete third-party programming API or stable SDK. [Operations](operations.md) · [Data and Security](data-and-security.md).
