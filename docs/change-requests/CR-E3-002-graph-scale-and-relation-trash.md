# CR-E3-002 — масштаб графа и удаление связи

Дата2026-10-09. Статус: принято в объёме прямого запроса владельца; отдельное окно редактора и правило подписей подтверждены. Координатор A.

## Конфликт и новая норма

ТЗ§8 и CR-E3-001 разрешали открывать полноценный редактор внутри графового узла. Владелец после просмотра результата требует оставить на карте только плитку с заголовком при приближении и иконку при отдалении. Это прямое изменение представления. Независимый инспектор и общий draft store сохраняются. Ответ владельца: «Да, редактор в отдельном окне». Double-click открывает полный редактор в отдельном диалоге; single-click выбирает инспектор. Старые saved expanded больше не должны превращать узлы в формы.

Линии должны быть видимы при всех поддержанных масштабах 0.1–2.5. Владелец подтвердил видимость подписей при 0.5–2× и допустимость скрытия при отдалении в 3–5 раз. Принятая реализация: подпись видима при zoom > 1/3, скрыта при zoom ≤ 1/3; геометрия и выбор линии от подписи не зависят.

Порог плитки — явно сообщённая настройка реализации: tile при zoom ≥ 1.25, icon ниже. Полный заголовок в данных не сокращается. Плитка показывает первые 40 видимых символов с многоточием; полный текст доступен через tooltip и accessible name. Это заменяет прежний fallback CR-E3-001 «длинный заголовок → иконка», чтобы представление определялось только масштабом. UI state v3 отбрасывает прежние expanded/sizes, сохраняя viewport, панели, инспектор и черновики.

## Удаление

Кнопка «Удалить связь» в просмотре конкретной Relation вызывает существующий CommandElementsTrash: nodeIds=[], relationIds=[id], groupMode=group_only. Физического DELETE нет: relations.deleted_at/deletion_batch_id и deletion_batches в одной транзакции. Поля/документы концов не меняются. Прежний запрос повторяется byte-identically; replay до проверки staleRevision/архивирования/soft-deleted состояния. Смешанные create/trash пакеты сохраняют исходную историю, не выдают старую relation за новую.

Этот пакет реализует только relation-only ветку elements.trash; nodeIds!=[]/неподдержанный groupMode явно отклоняются, не игнорируются. Полный интерфейс корзины/восстановление/группы/undo/redo остаются вне пакета. Новых API/SQL полей, миграций и dependencies нет. Общий E2/E3 gate и Q-04 сохраняют прежний статус.

## Проверка результата

Confirm/cancel/delete/reload/restart; duplicate/missing/cross/deleted/archived/stale/rollback/replay. Scale0.1/.25/.5/1/2 и переходы через границы: два вида узлов, отсутствие форм в canvas, стабильные пути/ID/endpoint, видимая экранная толщина, выбор связи без label, неизменная server revision. Отдельный редактор и инспектор сохраняют общий текст и5MiB limit. Подробные команды — задачи E3-005–008.

AC-05/06/07/08/18 применяются с этим изменением представления: редактор в диалоге вместо одновременно раскрытых A/B на графе; его закрытие не удаляет документ, а изменение размера узла происходит при смене масштаба. Это не приёмка старого требования о нескольких одновременно открытых canvas-формах. История предварительных трактовок и ответов сохранена в Context/Steps/Step-06.md.
