# TraceWeave на своём компьютере

Нужны Docker и папка поставки TraceWeave. После запуска приложение работает в браузере; отдельная установка backend, frontend и базы данных не требуется.

**Текущий статус:** готовые образы TraceWeave ещё не опубликованы. Запуск со скачиванием на новом компьютере станет доступен после первого публичного релиза. Команда для уже собранных образов на компьютере владельца приведена ниже.

## После публикации релиза

1. Установите и запустите [Docker Desktop](https://docs.docker.com/desktop/). Если Docker уже работает, этот шаг пропустите.
2. Получите папку опубликованной поставки TraceWeave. При установленном Git:

```sh
git clone https://github.com/andrey-torlopov/TraceWeave.git
cd TraceWeave
```

3. В терминале из этой папки выполните одну команду:

```sh
./bootstrap.sh
```

Скрипт скачает нужные образы, запустит контейнеры и подготовит базу данных. При первой установке введите email для входа, своё имя и пароль. Во время ввода пароль не отображается.

В конце появится адрес:

**http://127.0.0.1:8080**

Откройте его в браузере и войдите с указанными email и паролем. Локальный адрес доступен только на вашем компьютере. Для этого режима домен, SSH и почтовый сервис не нужны.

## Сейчас: уже собранные образы на компьютере владельца

На Mac, где выполнялась сборка поставки, команда такая:

```sh
/Users/andreytorlopov/Dev/Projects/ResearchGraph/SRC/TraceWeave/bootstrap.sh --release /Users/andreytorlopov/Dev/Projects/ResearchGraph/SRC/TraceWeave/releases/e8-docker-source.local.json
```

Она использует проверенные локальные образы приложения, при необходимости скачает официальный PostgreSQL, запросит данные первого аккаунта и покажет тот же адрес. На другом компьютере этот локальный файл не обеспечит скачивание приложения: его образы существуют только в Docker-хранилище этого Mac.

Если скрипт сообщает, что порт 8080 занят, повторите выбранную команду с `--port 18080`. Адрес будет **http://127.0.0.1:18080**.

## Следующие запуски

Из папки поставки:

```sh
./bootstrap.sh
```

Уже установленная версия запускается без повторного создания аккаунта. Чтобы остановить приложение:

```sh
./traceweave.sh stop
```

Остановка сохраняет исследования и вложения. Для следующего запуска снова вызовите `./bootstrap.sh`. Сохраните папку поставки с её `runtime/` и Docker volumes: там находятся настройки и данные установки.

Если установка оборвалась, повторите bootstrap с тем же файлом релиза; если скрипт требует восстановления операции, используйте [инструкцию управления](operations.md). Технические подробности и сборка разработчиком — в [полной инструкции установки](installation.md).
